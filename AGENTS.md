# AGENTS.md — ты в публичной вики Cognopolis

Этот репо — **вики игры для игроков и гостей** (kindomklaster.com/wiki): пересказывает истину
человеческим языком, сам истину НЕ хранит. Техническая документация для РАЗРАБОТЧИКОВ живёт
отдельно — в `../Train_of_Thought-Cognopolis-obsidian-for-man/`, и тон там другой: сухой. Правила — **`CLAUDE.md` здесь** (без статусов и дат,
без секретов, блок «Источники» на каждой странице, не дублировать справочники игры).

Роль в конвейере разработки (полная цепочка — `AGENTS.md` репо движка
`../Train_of_Thought-Cognopolis/`):

- **Ступень 4 «Док для людей»:** после обновления vault скилл `cognopolis-docs-human`
  (в `.claude/skills/` репо движка) находит затронутые страницы grep'ом по блокам «Источники»
  и переписывает их по обновлённой истине.

Истина всегда в vault `../Train_of_Thought-Cognopolis-obsidian/` — противоречие вики vault'у
чинится здесь.

**Пуш сюда публичен**: сайт собирается из этого репозитория пайплайном движка
(`.github/workflows/deploy-wiki.yml`) — при деплое игры автоматически, вне его — кнопкой
Actions → «wiki · build · deploy» → Run workflow. Собранного HTML в git нет, `site/` в
`.gitignore`: правится только `docs/`.
