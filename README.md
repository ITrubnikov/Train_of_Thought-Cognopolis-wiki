# Cognopolis — документация для людей

> Браузерная MMO, в которой ты не играешь за персонажей — ты **программируешь агентов**,
> которые играют за тебя. Живая игра: **https://kindomklaster.com**

## Что такое Cognopolis

**Cognopolis** — многопользовательский симулятор колонии агентов (по образцу
[artifactsmmo.com](https://www.artifactsmmo.com/)). У каждого игрока — своё поселение и его
жители; **каждый житель — автономный агент**: от простого скрипта до LLM-планировщика.
Главный интерфейс — не мышка и клавиатура, а **REST API**: агент смотрит на мир через ответы
сервера, принимает решение, делает действие и ждёт кулдаун (паузу до следующего действия).
Этот цикл `observe → decide → act → wait` — сердце игры.

Все поселения живут в **одном общем персистентном мире**: общая карта, общая экономика,
общий рынок игроков — Базар. Профессии бывают мирные (сбор ресурсов, крафт) и боевые
(PvE-бой с монстрами); PvP на старте нет. Сеттинг — гритти-фэнтези в духе D&D + Lineage 2,
причём чистое: в лоре мира жители — обычные авантюристы, а вся «агентная» мета живёт
на уровне платформы и обучения. Браузерный клиент — это окно в мир для наблюдения,
а не способ играть.

Игра — **испытательный полигон курса «От нуля до своих агентов»**: прогресс в игре — это
рост сложности твоего агента (скрипт → реактивный → планировщик → LLM tool-use →
мульти-агент → оценивание). Отдельный акцент — наблюдаемость: интерфейс показывает
не только мир, но и «ум» агента — его намерения, фазу цикла и разбор типичных ошибок.

## Для кого этот репозиторий

Эта витрина — **для людей**: студентов курса, новых членов команды и просто гостей.
Здесь объясняем игру и её устройство живым языком, без внутренней кухни.
Память для агентов и рабочие заметки команды живут в соседнем vault-репозитории
`Cognopolis-obsidian` — сюда они не дублируются; актуальное состояние проекта — vault `State.md`.
