# Cognopolis — документация для людей

Это **презентационный слой** проекта Cognopolis: вики для игроков и студентов курса.
Истину хранят код движка и vault команды — витрина их пересказывает по-человечески.

- Живая игра: **https://kindomklaster.com**
- Собранная вики: **https://kindomklaster.com/wiki**

## Что такое Cognopolis

Многопользовательский симулятор колонии агентов (по образцу
[artifactsmmo.com](https://www.artifactsmmo.com/)). У игрока — поселение и его жители;
**каждый житель управляется агентом**: от скрипта на REST до LLM-планировщика. Главный
интерфейс — API: агент смотрит, решает, делает действие и ждёт, пока житель освободится.
Мир, экономика и рынок общие для всех игроков. Браузерный клиент — окно в мир и способ
проверить механику руками.

Игра — испытательный полигон курса «От нуля до своих агентов»: прогресс в игре означает
рост сложности агента, а лестница тиров жителя зеркалит лестницу курса.

## Как это устроено внутри

```
mkdocs.yml            — конфиг рендера (Material, ru, тёмная тема, лупа на скриншотах)
build.sh              — сборка вики одной командой в site/
requirements.txt      — зависимости рендера, если ставить не через uv
docs/index.md         — главная страница вики (обложка с плитками)
docs/01-обзор/        — концепция и роадмап
docs/02-игроку/       — быстрый старт, тур по экранам, свой агент
docs/03-системы/      — механики игры
docs/04-разработчику/ — прежние копии страниц разработчика; в сайт не идут (build.sh вырезает),
                        истина — репо -obsidian-for-man
docs/assets/img/      — скриншоты игры с обводками-выносками
docs/assets/css/      — тема вики поверх MkDocs Material
tools/screenshots/    — харнесс съёмки кадров: shoot.py, shots.json, манифест IMAGES.md
```

Правила письма — [CLAUDE.md](CLAUDE.md); рабочий скилл — `cognopolis-docs-human` в репо движка.
Короткая версия: никаких статусов и дат, никаких секретов, каталожные числа (цены, рецепты,
формулы) не дублируем — на них ссылаемся, потому что они живут в игре.

## Сборка

```sh
./build.sh
```

Собирает статическую вики (MkDocs Material) в `site/`. Нужен `uv` — тогда ставить ничего не
надо; иначе `pip install -r requirements.txt`. Каталоги `.build/` и `site/` генерируются и в
git не идут.

### Публикация

Автоматическая: `git push` в этот репозиторий, дальше workflow `deploy-wiki.yml` **в репо
движка** (там ключи от прод-хоста) забирает этот репозиторий, гоняет его же `build.sh` и
раскладывает результат туда, откуда Caddy отдаёт `/wiki*`. Собранного HTML в git нет нигде.
Правка текста вики игру не редеплоит. Подробнее — «Деплой и прод» в репозитории
`Train_of_Thought-Cognopolis-obsidian-for-man`.

### Скриншоты

Кадры в `docs/assets/img/` снимает харнесс `tools/screenshots/shoot.py` с живой игры демо-аккаунтом:
обводки и номера рисуются поверх страницы перед снимком, токены размываются. Что где снято и что
обведено — `tools/screenshots/IMAGES.md`; кадры и выноски описаны декларативно в `shots.json`.
Номера в легенде под картинкой обязаны совпадать с номерами на картинке, а поменявшийся интерфейс
означает переснятый кадр.

## Соседние репозитории

| Репо | Что там |
|---|---|
| `Train_of_Thought-Cognopolis` | движок, SPA, workflow выкладки этой вики |
| `Train_of_Thought-Cognopolis-obsidian-for-man` | **техническая документация разработчику**: запуск и архитектура, деплой и прод, конвейер задач агентам, документация проекта |

оставшиеся здесь после переезда. В сайт они не попадают (`build.sh` вырезает раздел), а истина
по этим темам живёт в репозитории `-obsidian-for-man`.
