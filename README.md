# Cognopolis — документация для людей

Это **презентационный слой** проекта Cognopolis: вики для игроков и студентов курса.
Истину хранят код движка и vault команды — витрина их пересказывает по-человечески.

- Живая игра: **https://kindomklaster.com**
- Собранная вики: **https://kindomklaster.com/wiki**

## Что такое Cognopolis

Многопользовательский симулятор колонии агентов (по образцу
[artifactsmmo.com](https://www.artifactsmmo.com/)). У игрока — поселение и его жители;
**каждый житель управляется агентом**: от скрипта на REST до LLM-планировщика. Главный
интерфейс — API: агент смотрит, решает, делает действие и ждёт, пока житель освободится.
Мир, экономика и рынок общие для всех игроков. Браузерный клиент — окно в мир и способ
проверить механику руками.

Игра — испытательный полигон курса «От нуля до своих агентов»: прогресс в игре означает
рост сложности агента, а лестница тиров жителя зеркалит лестницу курса.

## Как это устроено внутри

```
docs/index.md         — главная страница вики (обложка с плитками)
docs/01-обзор/        — концепция и роадмап
docs/02-игроку/       — быстрый старт, тур по экранам, свой агент
docs/03-системы/      — механики игры
docs/04-разработчику/ — ВНУТРЕННЕЕ: в публичную вики не публикуется (build.sh вырезает)
docs/assets/img/      — скриншоты игры с обводками-выносками
docs/assets/css/      — тема вики поверх MkDocs Material
```

Правила письма — [CLAUDE.md](CLAUDE.md); рабочий скилл — `cognopolis-docs-human` в репо движка.
Короткая версия: никаких статусов и дат, никаких секретов, каталожные числа (цены, рецепты,
формулы) не дублируем — на них ссылаемся, потому что они живут в игре.

## Сборка

```sh
./build.sh
```

Собирает статическую вики (MkDocs Material) в `site/`. Нужен `uv` — тогда ставить ничего не
надо; иначе `pip install -r requirements.txt`. Каталоги `.build/` и `site/` генерируются и в
git не идут. Публикация на `kindomklaster.com/wiki` — маршрут Caddy в репо движка
(заготовка — `deploy/caddy-wiki-route.patch`), выкладка `site/` на прод делается вручную.

### Скриншоты

Кадры в `docs/assets/img/` сняты с живой игры демо-аккаунтом, обводки и номера нарисованы
поверх страницы перед снимком. Номера в легенде под картинкой обязаны совпадать с номерами
на картинке. Токены на снимках размыты.
