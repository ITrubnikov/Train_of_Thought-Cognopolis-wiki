# Скриншоты вики: как пересняться

Кадры в `docs/assets/img/` снимаются автоматически с **живой игры** демо-аккаунтом. Обводки и
номера рисуются оверлеем прямо в странице перед снимком, поэтому линии выходят чёткими, а не
дорисованными в редакторе.

## Одна команда

```sh
uv run --with playwright --with pillow python tools/screenshots/shoot.py
```

Снимет все кадры из `shots.json` и положит их в `docs/assets/img/` (webp, ширина 1600).
Можно снять только нужные:

```sh
uv run --with playwright --with pillow python tools/screenshots/shoot.py mir-karta lesopilka-tur
```

Если Chromium ещё не скачан: `uv run --with playwright playwright install chromium`.

## Как описан кадр

`shots.json` — список кадров. Поля:

| Поле | Что делает |
|---|---|
| `name` | имя файла без расширения; оно же цитируется в вики |
| `route` | маршрут SPA без решётки: `/`, `/world`, `/town-hall` |
| `url` | вместо `route`: снять сторонний адрес (например `/docs`) |
| `stage` | `login` — снять до входа в игру |
| `settle` | сколько ждать после перехода, мс |
| `before` | подготовка кликами: `["click","t:текст"]`, `["key","Escape"]`, `["mouse",["canvas",0.47,0.5]]`, `["js","…"]` |
| `callouts` | что обвести: `sel` + номер `n`; `frac` — доли габарита элемента (для объектов внутри канваса карты) |
| `clip` | кроп по элементу с отступом |
| `trim` | срезать почти-чёрный хвост снизу |
| `mask` | заблюрить элементы (токены!) |

Селекторы: `t:` — по тексту, `e:` — точное совпадение, `b:` — по роли кнопки, иначе CSS.

!!! Осторожно с `b:` — по роли кнопки ловится и кнопка аккаунт-меню в шапке (у неё
`title="аккаунт"` без текста). Для вкладок надёжнее `t:`.

## Правила, которые нельзя нарушать

1. **Номера легенды = номера на картинке.** Легенда живёт в вики в блоке
   `<div class="callouts" markdown>`; если поменяли порядок обводок — поправьте и легенду.
2. **Токены блюрятся.** Любой кадр, где видны токены жителей, снимается с `mask`.
3. **Переснимать после изменения интерфейса.** Если подпись кнопки или состав экрана поменялись,
   старый кадр начинает врать — это такой же баг витрины, как устаревший текст.
4. **Демо-аккаунт.** Кадры снимаются под демо-входом (`войти под тестовым пользователем`).
   Если тумблер демо-входа выключен на проде, снимать нечем — включите его или снимайте локально,
   поправив `BASE` в `shoot.py`.
